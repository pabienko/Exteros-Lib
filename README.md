# Exteros' Lib

The library mod every Exteros mod requires and installs automatically. Other modders can use it too - alone it changes nothing in the game.

[![Factorio 2.1](https://img.shields.io/badge/Factorio-2.1-orange.svg)](https://mods.factorio.com/mod/exteros-lib) [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

---

## Exteros' Hub

One settings window for every installed Exteros mod, instead of each one's own menu. Open with the toolbar button (next to copy and paste) or SHIFT + E, close with Escape.

- Mods listed on the left, their features and settings on the right.
- A disabled or conflict-blocked feature hides its settings.
- Global (server-wide) settings are visible to admins only.
- **Export / Import** - packs all settings into one line of text, to copy between servers or back up. Import reports what changed and skips what it doesn't recognize.

The Hub only changes settings of installed Exteros mods.

## For other mod authors

MIT-licensed, safe to depend on even without any Exteros mod installed. To plug into Exteros' Hub, see `event.lua`, `storage.lua`, `internal/manifest.lua` in the [GitHub repository](https://github.com/pabienko/Exteros-Lib).

---

## Installation

Install through the in-game mod manager, or from the [Factorio Mod Portal](https://mods.factorio.com/mod/exteros-lib). Installed automatically as a dependency of any Exteros mod.

## Compatibility

- **Factorio 2.1** only.
- **Space Age**, **Quality**, **Elevated Rails** - no difference either way.
